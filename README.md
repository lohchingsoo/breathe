# Breathe — web version

Box Breathing, 4 7 8 and guided sessions in a browser, with the same singing-bowl
cues as the iPhone app. Works on iPhone, iPad and desktop, and offline once
it's been opened.

It doesn't log to Apple Health, show heart rate, or run on Apple Watch — those
need the installed app.

## Guided recordings

The recordings aren't part of this site. Each device adds them once from its own
files (**Settings ▸ Recordings**); they're kept on that device and never uploaded.

## Publishing on GitHub Pages

1. Sign in at [github.com](https://github.com) (a free account is fine).
2. Top-right **+ ▸ New repository**. Name it `breathe`, leave it **Public**,
   click **Create repository**.
3. On the next page, click **uploading an existing file**. Drag in **everything
   inside this `web` folder** — the files *and* the `sounds` and `icons`
   folders. Click **Commit changes**.
4. **Settings ▸ Pages**. Under *Branch*, choose **main** and **/ (root)**, then
   **Save**.
5. After a minute or so the address appears at the top of that page, like
   `https://yourname.github.io/breathe/`.

> Upload only this folder's contents, never the whole `BreatheApp` folder — that
> one contains the recordings.

## On each iPhone or iPad

1. Open the address in **Safari**, tap **Share ▸ Add to Home Screen**.
2. Open Breathe from the Home Screen once while online, so it's saved for offline.
3. Put the recordings in the **Files** app (AirDrop them from the Mac), then in
   Breathe: **Settings ▸ Recordings ▸ Add several at once**, and select them all.
